# Week 4 – Task E: Fun In-Class Lab Performance Activity

## Objective
To demonstrate the behavior of different data structures (Linked List, Queue, Stack) using a fun, physical group activity.

## Group Roles & Data Structures

| Member | Role | Data Structure | Introduction Line |
|--------|------|----------------|------------------|
| Hadia | Idea Machine | Linked List | “Hi, I’m Linked List Hadia — I connect all our teachers and ideas smoothly, making sure nothing gets lost!” |
| Ayma | Sketch Artist | Queue | “Hello, I’m Queue Ayma — I line up the classes perfectly so every lesson happens in the right order!” |
| Nosheen | Narrator | Stack | “Hey, I’m Stack Nosheen — I keep track of the timetable so the latest updates are always easy to see!” |

## Demonstration Plan

### 1. Linked List (Hadia)
- Demonstrated forward and backward traversal of teachers.
- Showed adding a new teacher (node) and deleting a teacher.

### 2. Queue (Ayma)
- Demonstrated first-in-first-out (FIFO) order using lined-up classes.
- Added classes to the end and removed classes from the front.

### 3. Stack (Nosheen)
- Demonstrated last-in-first-out (LIFO) order for timetable updates.
- Showed push (adding new updates) and pop (removing latest updates).

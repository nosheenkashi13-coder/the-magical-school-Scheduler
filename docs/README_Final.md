# School Timetable Scheduler – Final Submission

## Project Summary
This project is a console-based School Timetable Scheduler developed using
core Data Structures concepts. It manages teachers, classes, and timetable
generation efficiently.

## Data Structures Used
- Doubly Linked List for teacher management
- Queue for class scheduling
- Stack for timetable storage and conflict checking

## Key Features
- Add, update, delete, and view teachers
- Add and manage classes using queue
- Automatic timetable generation
- Conflict detection using stack
- Reverse traversal of teachers

## How to Run
1. Open the project in a C++ compiler (Dev C++, CodeBlocks, or VS Code)
2. Compile the source file
3. Run the program
4. Use the menu options to perform operations
